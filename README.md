# 문장과 사유

개인 독서·사유·글쓰기 PWA입니다.

## 설치
GitHub 저장소 Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
배포 주소: https://luo4love.github.io/munjang-sayu/

## 개인정보와 제한
- PDF는 기기에서만 열며 서버에 업로드하지 않습니다.
- 독서 기록은 해당 브라우저 localStorage에 저장합니다. 기기 간 동기화되지 않습니다.
- JSON 백업을 정기적으로 저장하세요. PDF 원본은 백업에 포함되지 않습니다.
- 브라우저 저장 공간 삭제 또는 Safari/PWA의 저장 공간 분리에 유의하세요.
- PDF 페이지 이동은 브라우저 지원에 따라 다를 수 있습니다.
- 앱은 초기 시험판이며 아이패드 Safari에서 직접 검증이 필요합니다.
